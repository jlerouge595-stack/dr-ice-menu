# Dr Ice Mini App

Prototype de Mini App Telegram avec thème noir + bleu néon.

## Contenu
- Accueil
- Boutique et catégories
- Recherche
- Fiche produit
- Panier
- Informations
- Contact
- Profil
- Intégration de base avec Telegram Web Apps

## Mise en ligne
La Mini App doit être servie depuis une URL HTTPS publique.

1. Mets `index.html`, `style.css` et `app.js` sur un hébergement web HTTPS.
2. Récupère l'URL publique de `index.html`.
3. Dans BotFather : `/mybots` → Dr Ice → Bot Settings → Configure Mini App.
4. Active la Mini App et colle l'URL HTTPS.
5. Configure ensuite le bouton de menu pour ouvrir la Mini App.

## Personnalisation
Les produits de démonstration dans `app.js` sont volontairement génériques.
Remplace leurs noms, images, prix et descriptions par ceux de produits légaux que tu proposes.

Le personnage est représenté par un emoji de docteur dans ce prototype. Tu peux remplacer `.doctor-art` et `.big-avatar` par une illustration originale de ton personnage.
